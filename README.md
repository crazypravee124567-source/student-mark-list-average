 Student Marks Report

A simple web project that processes student marks data using core JavaScript array methods and displays the results in a clean, card-based UI.

---

Live Demo

> Open `students.html` directly in your browser — no setup needed!

---

Project Structure

```
student-marks/
├── students.html   # Main file (HTML + CSS + JS combined)
└── README.md       # Project documentation
```

---

Features

- ✅ Calculate **Total Marks** of all students
- ✅ Calculate **Class Average**
- ✅ Find the **Highest Scorer**
- ✅ Filter and display **Passed Students** (marks ≥ 50)
- ✅ Display **All Student Names**
- ✅ Clean and responsive UI with card layout

---

 JavaScript Concepts Used

| Concept | Used For |
|--------|----------|
| `Array.reduce()` | Calculate total marks & find highest scorer |
| `Array.filter()` | Filter passed students |
| `Array.map()` | Extract student names |
| `DOM Manipulation` | Display results on the page |
